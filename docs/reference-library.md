# Reference library

**Status:** Draft v0.2 · **Last updated:** 2026-10-13

Reports, standards and data sources that change rarely, so the agent doesn't check them weekly. Instead, it can cite them when drafting to ground a post. For example, a post about a new model launch is stronger with "but independent benchmarks show…".

## Rules for using an entry

- **Cite the primary source**, not a news article about it.
- **State the publisher and date** in the post, so readers can judge how current it is.
- **Respect the caveats column.** A contested figure is either presented with its caveat or not used.
- **Re-check before citing** if an entry is more than 12 months old, since newer editions often exist.
